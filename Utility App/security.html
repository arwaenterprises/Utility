Security

Utility by Arwa Enterprises · Last reviewed 1 October 2026

We want you to be able to trust Utility. This page says in plain words what we do, and links to independent public checks you can run yourself.

What protects your data

  • Google sign-in. You sign in on Google's page. We never see or store your password.
  • Encrypted connection. The site is served over HTTPS only.
  • Separate data per person and team. Database rules make sure you can read only your own data (and, in a team, the team's data where your role allows it). Team members cannot delete the team's data on the server; only the team administrator can.
  • Strict site rules. The site is set to run only its own code, to refuse being embedded in other sites, and to talk only to its own database. All the libraries it uses are hosted on our own site, not loaded from other companies' servers.
  • Camera on your device only. Barcode scanning happens in your browser.
  • Keep only what is needed. No ads or tracking in the app, and usage statistics are plain counts. Your data stays until you delete it.

Independent checks (1 October 2026)

These are automated public tools. Results are a snapshot in time; run them yourself for the current picture.

  • Google Safe Browsing: no unsafe content found. Check it yourself.
  • Qualys SSL Labs (HTTPS quality): grade A+. Check it yourself.
  • Mozilla HTTP Observatory (site security settings): run it yourself.
  • VirusTotal (multi-vendor URL check): see the report.
